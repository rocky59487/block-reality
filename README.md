# Block Reality

Minecraft 的結構工程沙盒。玩家用真實工法蓋房子，用真實力學知道它站不站得住。

三個構成：

- **設計層** — CAD 式的建造工具：polyline 繪製、精確尺寸輸入、osnap 吸附、全息預覽、變換 gizmo、delta undo
- **工法層** — 真實施工工序：綁筋 → 組模 → 澆置 → 養護 → 拆模。工序錯了有結構性代價，不只是視覺
- **力學層** — 真正的有限元素分析。6-DOF 樑柱 + MITC4 殼、稀疏直接解、per-member 內力與 D/C

力學引擎在 process 之外，透過凍結的 C ABI 呼叫。**換引擎不動 Minecraft 側**。

## 這個倉庫與前身的關係

前身是 `block-reality-api` 與 `PFSF-CORE`。本倉庫**只帶設計，不帶程式碼**。

前身的物理引擎 PFSF 每體素只有一個純量自由度，解的是穩態擴散方程而非彈性方程 —— 梯度的旋度恆為零，算不出純剪力與扭轉，也表達不了彎矩。這是結構性限制不是實作缺陷，因此整個力學層重做。

驗屍紀錄與六倉庫調查見 `docs/DECISIONS.md` D-001。
