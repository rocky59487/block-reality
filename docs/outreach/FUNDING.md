# Hack Club 與資助管道

## Hack Club(如果你 ≤ 18 歲 / 高中生——他們的資格線,先確認自己符合)

**是什麼**:全球高中生 hacker 社群(非營利 501(c)(3)),Slack 為主要聚集地,
免費、不收費用。

**怎麼加入**:
1. [hackclub.com](https://hackclub.com/) → Join Slack。自我介紹頻道直接放
   Block Reality 的 GIF——這種「真的會動的專案」在那裡很受歡迎
2. **YSWS(You Ship, We Ship)**:[ysws.hackclub.com](https://ysws.hackclub.com/)
   ——做出東西就換獎勵(硬體、額度等)的系列計畫,每檔獨立、可重複參加。
   Block Reality 這種規模的專案幾乎每一檔泛用型 YSWS 都能投;上去看**當期**
   開放哪些(計畫輪替快,列清單會過期)
3. 附近或線上的 [hackathon](https://hackathons.hackclub.com/):把 mod 帶去
   demo,是找隊友與曝光的捷徑

**HCB(Hack Club Bank,fiscal sponsorship)**:
[hackclub.com/fiscal-sponsorship](https://hackclub.com/fiscal-sponsorship/)。
把專案掛在他們的 501(c)(3) 底下,就能**合法收捐款、開發票、管帳**(700+ 個
青少年團隊在用)。適用時機:等你要收贊助、辦工作坊、或申請只發給法人的
grant 時再開,單純開發階段不需要。

## 其他資助管道(不限年齡)

| 管道 | 適合階段 | 備註 |
|---|---|---|
| **GitHub Sponsors** | 現在就能開 | repo 加 `.github/FUNDING.yml`;零成本,姿態是「buy me a build server」 |
| **Modrinth creator rewards** | 上架後自動 | 依下載/瀏覽分潤,金額小但零工作量 |
| **課程/系上的 undergraduate research 經費** | 接觸到教授後 | 教授合作最實際的產出常是「掛在他的計畫下當 RA/專題」——這比任何 grant 都穩,OUTREACH.md 的信就是入口 |
| **科展/競賽**(若在學) | 有 demo 影片後 | 工程教育類獎項吃「驗證紀錄」這套;evidence/ 目錄就是你的展板 |
| **NLnet / 開源基金類** | 專案更成熟後 | 門檻高、週期長,先擱置 |

## 申請材料的共通骨架(寫一次,改標題重用)

1. **一句話**:Minecraft 裡的真有限元素分析——方塊變構件,應力畫在方塊上
2. **證據**:41 項閉合解 gate（全套 282 項）、1.2e-14、跨平台逐位元決定性、開源 Apache-2.0
3. **教學主張**:玩家在遇到公式之前先遇到挫屈(P_cr ∝ 1/L²)
4. **要什麼**:具體金額/資源 + 用途(例:美術素材、伺服器、參加 hackathon 的旅費)
5. **連結**:repo、release、demo 影片
