# 教學設計移植清單

來源：`rocky59487/tvet-mechanics`（統測力學 V10.3.0-alpha1，Kotlin/Compose Android + Node server）。

這是同一位作者**目前正在做的**力學教學產品，對象是技高土木與建築群學生——**與本專案的目標族群完全相同**。它是「怎麼教這群人力學」最新、最完整的思考。

⚠️ 兩件事要先講清楚：
1. 它的力學範圍是**平面、靜定、線彈性、小變形**——不是 FEA 驗證基準，但**是教學語彙與符號慣例的 oracle**
2. 它有一條「不畫倒塌動畫」的護欄，**本專案不能照抄結論**（見 §7）

## 2. ⭐ 符號慣例與「事件不可平滑」

### 梁正負號約定（逐字，可一字不改照用）

> **向下載重＋・逆時針力偶＋・向上反力＋；V、M 正值畫在基準線上方，事件保留左右側。**

引擎端一致：`dV/dx = −w`、`dM/dx = V`、`ΔV = −P`、`ΔM = −C`。

### 🔴 事件左右側是一等公民

同一 `x` 保留**兩個頂點**，跳躍**不被插值**。程式碼落實：
```kotlin
listOf(probe.left.shear, probe.right.shear).distinct()   // 畫成兩顆分開的小圓點
```

**本專案的 member 內力圖（`N, Vy, Vz, T, My, Mz` 沿桿長）在節點與集中載重處必定跳躍。這條規則直接沿用。**

同理：剪應力 ribbon **依 region 邊界分段**（每段 9 個取樣點，端點分取 `ABOVE`/`BELOW`），**翼板↔腹板的 τ 跳躍不會被平滑掉**。

### 符號轉換只在 engine 邊界做一次

> 拉力、壓力、剪力、彎矩、tensor shear 與莫爾圓 plotting shear 的正負慣例**在 engine 邊界轉換一次**，UI 不得再轉。

莫爾圓專屬：`τ_plot = −τ_tensor`，明文寫在 UI 上。

## 3. ⭐ 應力分布的畫法（本專案要顯示的正是這個）

**正應力 ribbon**：畫在截面右側 `x = 0.73 × 寬`。以 line-strong 垂直軸為基準，`σ = N/A − M(y−ȳ)/I` 直接算，對 `max|σ|` 正規化、外伸 `0.075 × 寬`。填 `TealWash`、描邊 `Teal`。
→ **四點多邊形，所以線性分布與中立軸位置直接可讀。**

**剪應力 ribbon**：`x = 0.90 × 寬`，赭色**分段**折線。preview 狀態用 58% alpha + 虛線。

### 六種分布形狀選項預覽（直接抄）

`BENDING_LINEAR_SIGNED`（上半藍向左、下半赭向右）/ `BENDING_UNIFORM` / `BENDING_EDGES_ONLY` / `SHEAR_PARABOLIC`（`quadraticTo` 拋物線）/ `SHEAR_UNIFORM` / `SHEAR_LINEAR`

> **「讓學生選分布形狀」比「讓學生填數字」更能診斷模型是否建立。**

配合的教學順序（I-36 TalkBack 逐字）：**「彎曲三角形與剪應力拋物線僅顯示形狀；應力數值尚未揭示」——形狀先給、數值後給。**

## 4. ⭐ 誤解目錄（最難重建、最直接可用的資產）

### 資料模型

```
(interactionId, wrongOption) → (misconceptionId, whyWrong, repairAction)
```

三個設計特徵值得逐一照抄：

1. **診斷只指出學生選的觀念，不揭露答案**
2. **`wrongOption` 文字直接引用題目 spec，啟動時 `check()` 比對 ID 集合與數量——文案一改就 fail closed**，不會把舊診斷掛到新答案上
3. **`repairAction` 一律是「回畫布做一件具體的事」，不是重述公式**

範例（逐字）：

| misconceptionId | whyWrong | repairAction |
|---|---|---|
| `i34-uniform-bending-stress` | 彎曲時，各纖維離中立軸的距離不同，不會承受同一正應力。 | 把 y 從 A 拖到 B，經過中立軸時比較 σ 的大小與符號。 |
| `i42-must-guess-tension-compression-first` | 列式時可先假設桿力方向，解出的符號會負責修正假設。 | 先把未知桿全畫成拉力，完成平衡後用 N 的符號判讀拉壓。 |
| `i44-zero-shear-means-zero-moment` | V=0 說明的是 M 圖斜率，不是 M 本身的高度。 | 找到 V 變號點，停住後直接讀同一 x 的 M。 |
| `i38-principal-plane-has-max-shear` | 主平面的特徵是剪應力消失，不是剪應力到頂。 | 在莫爾圓上分別點選 σ 軸交點與圓頂，比較 τ 座標。 |

另有 **650 題題庫，每題一條 `trap` 欄位**——現成的繁中誤解語料。節錄幾條與本專案直接相關的：

- 「**依支承圖示外形背答案，沒有從被限制的自由度判斷。**」
- 「把鉸支承當固定端，多畫一個反力矩。」
- 「只看到兩桿相接就判零，忘了確認兩桿不共線且節點沒有外作用。」「只報大小不判拉壓。」
- 「**誤認簡支點的內彎矩必為零；外伸梁在中間支承處可有非零內彎矩。**」
- 「把平均剪應力 `V/A` 當最大值；矩形最大值是平均值的 **1.5 倍**。」
- 「看到腹板較薄就誤以為承受較少剪力；同一剪流通過較薄材料時，**剪應力反而較大**。」
- 「**零力桿不等於可刪除**；本配置移除 BD 會形成機構。」

### 🔴 「單次錯答不能建立永久診斷；只有重複模式才影響後續支架。」

## 5. ⭐ 回饋文法（硬性）

固定三部分、**最多兩行**：

1. **目前證據** — 「ΣMx 仍為 +12 kN·m」
2. **下一個判斷** — 「先把 B 反力往下調，觀察力矩是否接近 0」
3. **必要時的模型規則** — 第二次以上錯誤才顯示

**禁止**：「答錯了，再試一次」而沒有可操作方向 / 第一次錯就公布完整答案 / 制式「太棒了、你真厲害」/ **使用「AI、智慧、神奇」等字眼替代具體證據** / 用紅色長篇段落一次列出所有問題。

範例語氣（逐字）：「切線有效；現在選一個能消去兩個未知桿力的取矩點。」

**對本專案**：崩塌後的診斷畫面就該長這樣——「柱 C3 的 D/C = 1.34，控制項是 `My`」+「先看它上方哪一根梁把彎矩傳下來」，**而不是「你的建築倒了！再試一次」**。

### 錯因自陳七分類

答錯後可選「這題主要錯因」：**模型判斷 / 方向與正負 / 方程選擇 / 代數運算 / 單位換算 / 讀題理解 / 時間管理**。

這七類把「不會」拆成可行動的維度，值得照搬。

## 6. ⭐ 互動設計：一次失敗的完整根因分析

`interaction-design-v2.md` 記錄了三代演進，**其中 v2 是失敗的**，而失敗分析本身最有價值。

### v2 失敗的根因（逐字）

> 固定比例密集畫布（梁 1m≈39dp、桁架 1m≈28dp、細格 ≤7dp）上，**固定 dp 參數**使捕捉區覆蓋大半軸長、脫離距離 > 格距——**「經過就吸、快慢無差、粗細無感」是幾何必然。**

對策原則：**參數禁止固定 dp，一律由格距 pitch（px）在 runtime 推導**（capture = 0.30×pitch，break = 0.55×pitch）。

### v2.2（現行）— 「多按一指＝微調」

使用者裁決原話：
> 「節點那個很難超出框框，所以用一指拉很快，畫面兩點觸控時微調…做到像是頂級設計師做的商業教育軟體」

- 一指拖 = 1×；**第二指按住畫布 = 微調**（`WORKBENCH_FINE_RATIO = 0.25f`）
- **增量映射**（video-scrub 標準）：每幀 `Δ手指 × 當前比率` 累加到值，**不做絕對映射**——拉遠時 handle 不跳
- **隱形格點**：量化落點 + 跨格觸覺，但**不畫刻度、無磁吸滯留**。放手永遠落在乾淨值，**永不顯示原始小數**

品質鐵則逐字：**「無 AI 味、無標語、無驚嘆號」**；「微調」以小字安靜出現於讀值旁；**等寬數字**。

### 驗收方法值得學

作者寫了一個 `interaction-v2-simulator.html`（五參數即時可調的網頁模擬器），**讓使用者親手試手感再回覆數字，主迴圈才實作**。

### 觸覺護欄 🔴

> 連續 drag pulse 的強度與頻率可由速度分段，但**不得把觸覺當成待求答案的精密指示器**。學生不能只靠震動找到 V=0、臨界摩擦或主方向；**接近程度由可見殘差與數值證據表達**。

節流 `MINIMUM_SAFE_INTERVAL_MILLIS = 72L`（≈14 次/秒上限）。

### Motion tokens

| Token | 時間 | 用途 |
|---|---:|---|
| `instant` | 0 ms | 跟手拖動、數值更新 |
| `micro` | 90 ms | 按鈕壓下、選取外框 |
| `standard` | 160 ms | Inspector 展開、結果 crossfade |
| `emphasis` | 220 ms | 磁吸回位、合法 commit、**分析 lens 切換** |
| `explain` | 360 ms | **單步力流揭露**（只在使用者主動執行後） |

**「一個 pointer update 只能產生一種 cue」** — 防止回饋轟炸的最簡規則。

## 7. ⚠️ 學術誠實護欄 — 移植原則，不移植結論

該 App 有這條：

> 靜力分析**不得用誇張倒塌動畫**暗示已做強度、挫屈或動力分析。
> 若顯示變形，必須標示「放大示意」與使用的線彈性模型；**沒有剛度資料時只顯示力流，不畫假變形**。

**這條對它完全正確**——它沒有做強度／挫屈／動力分析，播倒塌就是學術造假。

**但本專案有真 FEA 與 D/C 利用率，崩塌是產品核心。** 要移植的是背後的原則：

> ### 🔴 動畫只能表達你真的算過的東西。

推論：

| 可以畫 | 條件 |
|---|---|
| 崩塌 | **必須可追溯到 `D/C > 1` 的具體構件與控制內力分量** |
| 變形 | 必須標示**放大倍率**與模型（線彈性 vs 幾何非線性） |
| 力流 | 「這是分析結果的**敘事排序**，不模擬時間或衝擊」 |

| **不可以畫** | 理由 |
|---|---|
| 疲勞 | 沒算 |
| 材料破壞後行為 | 沒算 |
| 挫屈（在只做線性分析時） | 沒算 |

彈性曲線標籤逐字：**「彈性曲線（形狀放大）」**——放大這件事寫在標籤上，不是藏在文件裡。

另一條可直接用的：**「答案揭露前的圖、數值、TalkBack 描述與題卡預覽都不能偷渡待求量。」**

## 8. 跨尺度五層鏡頭（架構設計，可直接搬）

```
STRUCTURE → FREE_BODY → MEMBER → SECTION → MATERIAL_POINT
```

每層有型別化輸入輸出與**跨尺度不變量**，並用 `SectionActionSource`（`TrussMember` / `BeamStation` / `Column`）當**物理防線**，防止不同理想化互相偽裝。

**本專案的縮放式檢視（整棟 → 一根梁 → 一個截面 → 一個材料點）幾乎可以直接搬這個型別設計。**

配套的**七個分析鏡頭**（同一模型換鏡頭，不換計算器）——桁架版是建模／合法性／穩定性／整體 FBD／桿力圖／Joint FBD／Section FBD。本專案版可以是：

> 建模 / 連通與支承合法性 / **穩定性（機構偵測）** / 整體反力 / 構件力圖（六分量）/ 節點平衡 / 截面 D/C 熱區

並保留**可逆導覽**：從構件力圖點一根構件回到它的節點，或從節點回看整體。

🔴 **「點誰，就看誰的自由體圖」是整個設計的靈魂**——而它在遊戲裡遠比在題庫 App 裡合理。

## 9. 學習節奏

**五段**：預測 → 操作 → 取證 → 解釋 → 遷移（一節 5–12 分鐘）
**七段旗艦**：PREDICT → WORKED → TRACE → EXPLAIN → VARIANT → TRANSFER → COMPLETE

對齊本專案的 設計 → 施工 → 加載 → 崩塌 → 診斷 → 改：

> **預測（會不會倒？哪裡先壞？）→ 施工 → 加載取證 → 崩塌即證據 → 診斷解釋 → 改一個變因再驗**

🔴 **關鍵是把「崩塌」定位成取證階段，不是失敗懲罰。**

### A/B 單變因實驗 ⭐

> 複製目前模型，**只允許改一個變因**。

在沙盒裡就是「把這根柱加粗一級，其他不動，再加載一次」——並**強制先押趨勢再看結果**。

**這是把沙盒從玩具變成實驗室的單一最關鍵機制。**

### 完成頁三問

**剛才證明了什麼 / 哪裡仍不穩 / 下一步** — 取代星星與彩帶。

### 題內適應規則

| 證據 | 動作 |
|---|---|
| 第一次答對、確定、無提示 | 一行確認後進入較遠遷移題 |
| 答對但**不確定** | 插入缺一步例題再前進 |
| 第一次答錯且能辨認迷思 | 給兩行內的針對性提示，**不公布答案** |
| 第二次仍錯 | 標出圖中相關位置或揭露**一條**規則 |
| 第三次仍錯 | 示範目前步驟，接一題較簡單的**平行題** |
| **高信心答錯** | 優先處理概念迷思，**不以大量刷題取代** |

## 10. 驗收 oracle（可直接對數）

矩形梁應力（I-36 官方案例，**明說「只作人工 oracle，不能成為第二套 production 計算」**）：

| 案例 | b | h | M | V | \|σ\|max | τmax |
|---|---:|---:|---:|---:|---:|---:|
| A 基準 | 100 mm | 100 mm | 20 kN·m | 30 kN | **120 MPa** | **4.5 MPa** |
| B 高度加倍 | 100 mm | 200 mm | 20 kN·m | 30 kN | 30 MPa | 2.25 MPa |
| C 寬度加倍 | 200 mm | 100 mm | 20 kN·m | 30 kN | 60 MPa | 2.25 MPa |
| 獨立題 | 80 mm | 160 mm | 12 kN·m | 24 kN | 35.15625 MPa | 2.8125 MPa |

**注意 A→B**：`σ` 變 1/4（`h²`）、`τ` 變 1/2（`h`）。**整個 I-36 關卡就是為了這個指數差設計的**，而「`σ→1/2、τ→1/4`」是最常見的錯誤模式（把 `h²` 與 `h` 對調）。

跨尺度 fixture：屋架反力 12／12 kN、樓梁反力 19／21 kN、柱段與基礎 31／33 kN；樓梁 `x=4 m` 切面 `V=3 kN、M=44 kN·m`。

桁架基準：`P=12 kN、h=3 m` → 斜桿各受 **10 kN 壓力**、下弦各受 **8 kN 拉力**、BD 為零力、`Ay=Cy=6 kN`。

## 11. 一個影響產品方向的實證發現

`official-question-style-audit.md` 稽核 113/114/115 三年正式卷 Q1–20（共 60 題）：

| 指標 | 113 | 114 | 115 | 合計 |
|---|---:|---:|---:|---:|
| **必須讀圖或圖形選項** | 16/20 | 19/20 | **20/20** | **55/60** |
| 圖形答案選項 | 1 | 4 | 2 | 7/60 |

結論逐字：
> 這是三個年度、60 題的視覺樣本，**足以否定「統測力學主要是純文字代公式題」的產品假設**。
> 最大風格缺口是**跨表示**，不是計算量。

**這強力支持本專案應該優先訓練圖形推理而非數值計算**，並支持圖形化選項（讓玩家選 V/M 圖形狀而非填數字）。

## 12. 明確不要照抄

| 項目 | 理由 |
|---|---|
| 「不畫倒塌動畫」的**結論** | 見 §7——原則要，結論不要 |

## 13. 最強的一課：宣稱紀律

該倉庫對「已完成」的定義極嚴格，並反覆用「**這只證明 X，不證明 Y**」的句式自我約束：
