# Installed placement boundary qualification

Frozen before the next installed run, 2026-09-10. Production remains a5900cd and
ordinary candidate FOURTH. This extends CT_TRANSACTIONAL_PLACEMENT; it does not
replace the existing crash, actual-client, native or multi-cell criteria.

Use authenticated synthetic ServerPlayers in a fresh owned installed Forge server.
Exercise the ordinary production service, including its normal tick-based admission;
do not clear rate/offer maps or alter its clock to make a request pass. Retain the
first failure, raw server/class-load logs, request bindings, snapshots and timings.

- A stored terminal request with another actor or changed offer, domain, session,
  base revision or plan hash returns CONFLICT. Exact retries return the same receipt.
  A new UUID cannot reuse the consumed offer. No refusal or replay changes items,
  world, manufactured identity, revision, publication, player files or old journals.
- An unexecuted foreign actor/token or old session has no matching live offer and
  returns EXPIRED; a foreign domain, base revision or hash returns CONFLICT. These
  pre-admission refusals allocate no journal/player file.
- Changed selected slot, held NBT/product, target, game mode or reach must prevent
  the old plan from executing. A legitimately admitted validation rejection may
  store its REJECTED receipt, but cannot checkpoint a player, debit or publish.
  Snapshot after the legitimate fixture change to distinguish it from execution.
- Adventure, out-of-reach, foreign dimension and nonempty cursor previews refuse
  without writing. A replacement preview invalidates the old offer. At 200 elapsed
  server ticks the offer expires; elapsed real time does not substitute for ticks.
- Eight invalid requests or exact replays exhaust the actor's 20-tick window; the
  ninth is RATE_LIMITED. Admission resumes after real server ticks. The 65th actor
  cannot evict any of 64 live offers; logout releases only that actor's offer.
- Main-hand/offhand Count=1 removes exactly that saved inventory entry. An offhand
  larger stack changes only its Count byte. Every other slot, selected index and
  typed item NBT remains exact, and the saved inventory agrees with the live one.

Record elapsed nanoseconds and, where the JVM exposes it, calling-thread allocated
bytes around production preview/confirm calls. This is a correctness fixture with
synthetic players on one machine, not a performance threshold, FPS or soak result.
Additional capability, reentrant-hook, full-player extension and client accessibility
cases remain required even if this boundary group passes.

Additional actual-client workflow, frozen before running it: a test-only socket
observer drops one outbound confirmation before the server handles it. After at
least 200 actual server ticks, an explicit byte-identical retry receives EXPIRED.
Closing, timeout and EXPIRED alone must retain the pending record; only the labelled
new-preview action releases that exact record. New preview must allocate no durable
construction. Only a separately confirmed new UUID may commit and debit once.
Preserve raw frames, both endpoint states, outbox bytes and small/large Chinese
screenshots. Test actual overflow with a supported small GUI width and the real
unresolved-request message; PageDown must change measured scroll and keep controls visible.
The native narration message must include product, material cost, target and current
status, with focused controls still narrated by Minecraft. Text collection is not
evidence that the host's audio/TTS device spoke it.
