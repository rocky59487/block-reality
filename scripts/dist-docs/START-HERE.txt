Block Reality — Demo v0
=======================

Structural analysis for Minecraft, solved by a real finite element engine.
Requires Minecraft 1.20.1 with Forge 47.x.


INSTALL
-------
Windows   double-click  install.bat
Linux     ./install.sh
macOS     ./install.sh

With no arguments the installer looks for a Minecraft instance in the usual
locations for the vanilla launcher, Prism, MultiMC, Modrinth and CurseForge. If
it finds one it uses it; if it finds several it lists them and asks which. You
can also name the directory yourself:

    install.bat "D:\games\my-instance\.minecraft"
    ./install.sh ~/.minecraft

    install.bat --list        list what was found, install nothing
    ./install.sh --list

The directory to give it is the game directory: the one containing mods/ and
saves/.


CONTENTS
--------
  blockreality-*.jar     the Forge mod                 -> <instance>/mods/
  br-sidecar[.exe]       the analysis engine           -> <instance>/
  install.bat/.sh        installer
  VERIFICATION.md        verification record for this build
  verification.json      the same record, machine readable
  SHA256SUMS.txt         hashes of every file in this archive

FrameCore is statically linked into br-sidecar, so there is no separate library
to install. br-sidecar runs as its own process rather than as a library loaded
by the mod: a fault in the C++ costs one analysis rather than the server and the
save.

The mod locates the engine in this order: the config file, -Dbr.sidecar, the
BR_SIDECAR environment variable, the game directory, then PATH. The engine is
optional — without it the mod loads and plays normally, with analysis disabled
and reported as such.


IN GAME
-------
Creative tab "Block Reality": Structural Steel, Concrete Slab, Stress Glasses.

The two blocks are two different element types, not one type in two colours:

  Structural Steel   steel_rect_200x400   6-DOF beam, 200 x 400 mm section
  Concrete Slab      concrete_slab_200    MITC4 shell facet, 200 mm thick

First case — a cantilever:

  1. Place five Structural Steel blocks in a line out from a solid stone wall.
     The block touching the wall is treated as grounded.
  2. Hold the Stress Glasses.
  3. Sneak-right-click the far end to apply a 20 kN test load.

Look at the beam and the section diagram appears in the corner: the stress
profile through the section depth, the neutral axis, and the extreme fibre
values in text.

Whether the top fibre is in tension or compression depends on the structural
form, not on the beam. A cantilever hogs, so its top fibre is in tension; a beam
supported at both ends sags, so its top fibre is in compression. Both readings
are correct, which is why the HUD states them in words rather than leaving them
to be inferred from colour.

Right-click the air to change lens: Utilisation -> Stress -> Material.

Cases worth trying:

  Nothing supporting it     reported as a mechanism rather than a structure.
                            Nothing is holding it up, so there are no stresses.
  Overloaded                max D/C rises above 1 and the member turns red.
  Tall slender column       stress D/C stays low while the buckling load factor
                            drops below 1. Strength and stability are different
                            questions.


COMMANDS
--------
  /br status         engine state, every path searched, last result
  /br members        per member: D/C, governing fibre, governing section, peak
  /br section <id>   per station, in text
  /br scan           re-read loaded chunks, for blocks placed by command or
                     WorldEdit
  /br resolve        force re-analysis
  /br reset          restart the engine after it has been disabled (OP only)


SCOPE
-----
Implemented: 6-DOF beams, MITC4 shells including floors and shear walls, linear
buckling for beams and columns, per-member and per-shell D/C, surface stress
contours.

Not implemented: geometric stiffness for shells, so buckling does not cover
in-plane shell buckling; ultimate strength for shells; transverse shear in the
D/C screen; composite reinforced-concrete sections; nonlinear post-buckling.

Every solve returns a global equilibrium residual computed independently from
geometry and density rather than read back from the assembled load vector. The
verification record for this build is in VERIFICATION.md.
